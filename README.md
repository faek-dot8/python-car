# Python Car

A simple Python project built to practice **Object-Oriented Programming (OOP)**.

## About

This project implements a `Car` class with attributes and methods to represent a car and simulate basic actions.

## Features

- Store car brand, model, and year.
- Simulate driving and stopping.
- Display car information using `__str__`.
- Receive car details through user input.

## Technologies

- Python 3
- Object-Oriented Programming (OOP)

## How to Run

1. Make sure Python 3 is installed.
2. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/python-car.git
   ```

3. Navigate to the project directory:

   ```bash
   cd python-car
   ```

4. Run the program:

   ```bash
   python3 main.py
   ```

## Learning Goals

This project was created to practice Python classes, objects, methods, attributes, and string representation.
